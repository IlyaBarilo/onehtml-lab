# Исходники и сборка

Готовое приложение — корневой `onehtml-lab.html`: самостоятельный HTML-файл без зависимостей во время работы. При публикации выпуска workflow создаёт из той же сборки копию с именем `index.html` для GitHub Pages. В репозитории хранится один готовый HTML-файл. Коммиты в `main` запускают проверки, но не обновляют Pages; страница обновляется при публикации выпуска.

Для пересборки и проверок нужен Node.js 20 или новее. Из корня проекта выполните:

```cmd
node build.mjs
```

`src/template.html` задаёт разметку и политику безопасности, `src/styles.css` — оформление, `src/icons/` — SVG-значки, а `src/examples/` — игры-примеры. `src/app.js` управляет интерфейсом, `src/draft.js` хранит черновик и историю в IndexedDB, `src/compare.js` строит различия, `src/exporter.js` сохраняет и отправляет файл, `src/library-bundle.js` распознаёт точные версии классических библиотек, загружает их вместе с MIT-лицензией по явному действию пользователя и хранит в отдельной базе IndexedDB, а `src/sandbox.js` создаёт изолированный предпросмотр и сообщает об ошибках игры. Все поддерживаемые библиотеки, включая Three.js r128, загружаются одинаковым способом; готовых копий библиотек игр в сборке редактора нет. Загруженное встраивается в сохранённую игру с выбранным флажком «Встроить библиотеки в файл». Для запуска самого редактора внешние шрифты, библиотеки и сервер не используются.

Для проверок установите зависимости разработчика и запустите отдельные наборы:

```cmd
npm ci
```

```cmd
npm run test:unit
```

```cmd
npx playwright install chromium webkit
```

```cmd
npm run test:e2e
```

```cmd
npm run test:stage7
```

Тест браузера по умолчанию открывает локальный `onehtml-lab.html`. Команда `node tests/browser.mjs --http` дополнительно проверяет страницу через временный HTTP-сервер; он не нужен для использования приложения. Результаты сохраняются во временный каталог системы или по пути `TEST_RESULTS_DIR`.

Публикационная сборка получает номер из тега выпуска: `node build.mjs --release-tag=v1.0.0`. Обычная локальная сборка не показывает номер версии. Автоматические проверки и выпуск описаны в файлах `.github/workflows/`.

Локально подготовить тот же пакет для Pages можно командой `node scripts/prepare-pages.mjs` после сборки. Файл появится в `dist/pages/index.html` и должен побайтно совпадать с корневым `onehtml-lab.html`; проверить это можно командой `npm run test:pages`. Каталог `dist/` не входит в коммит.

Изображения интерфейса в `assets/` можно обновить командой `node scripts/capture-assets.mjs` после пересборки. Она делает снимки настоящего приложения; для неё нужен установленный Playwright Chromium.
