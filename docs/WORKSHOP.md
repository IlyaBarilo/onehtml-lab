# Занятие с OneHTML Lab

Цель — сделать небольшую игру, проверить её, внести улучшение и унести с собой рабочий HTML-файл. Начать можно на телефоне; компьютер подходит для более подробного редактирования. Сценарий не требует общего сервера или регистрации в редакторе.

## Подготовка

1. Дайте участникам [ссылку на приложение](https://ilyabarilo.github.io/onehtml-lab/) и [последний выпуск с файлом onehtml-lab.html](https://github.com/IlyaBarilo/onehtml-lab/releases/latest). Для работы без сети заранее скачайте файл и проверьте его открытие в браузере на устройствах участников. Одного посещения сайта для работы без интернета недостаточно.
2. Проверьте доступ к выбранному ИИ-боту и возможность скопировать из него полный HTML. Редактор готовит запрос, но отправляет его боту сам участник.
3. Покажите кнопку `?` возле названия: памятка доступна в простом и экспертном режимах. Она открывается вместо рабочей области; крестик возвращает предыдущий экран без потери кода и без перезапуска игры.
4. Для запасного сценария используйте «Примеры игр» → «Готовые игры». Эти примеры находятся внутри редактора и не требуют внешних библиотек. Чтобы увидеть примеры и запросы, включите экспертный режим кнопкой с шестерёнкой.
5. Если занятие использует библиотеки, заранее загрузите нужные версии через редактор. Сохраните игру с параметрами «Встроить библиотеки в файл» → «Внутри HTML», затем проверьте скачанный файл с отключённым интернетом. Встраиваются подготовленные библиотеки, а внешние картинки, звук и прочие ресурсы остаются отдельными зависимостями. Кэш другого браузера, локального файла или страницы сайта не следует считать общей копией.

## Основной сценарий

1. **Идея.** Участник выбирает одну понятную механику: поймать цель, найти пару, избежать препятствий. В «ИИ и запросы» выбирает «Новая игра», основное устройство и описывает свою идею. Выбранное устройство определяет главный вариант экрана и управления; запрос предусматривает поддержку остальных устройств.
2. **Первый запуск.** Участник копирует подготовленный запрос в ИИ-бота, затем переносит полный HTML из ответа в редактор. Пояснения и ограждения блока кода из трёх обратных кавычек копировать не нужно. Кнопка «Вставить» заменяет весь код. При вставке через меню поля для полной замены сначала нужно выделить всё.
3. **Проверка.** Нажать «Запустить», попробовать управление, достижение цели и повторную игру. «Стоп» возвращает код. На компьютере можно включить «Код и игра рядом»; изменения применяются по кнопке «Перезапустить».
4. **Одно улучшение.** Выбрать «Изменить» в «ИИ и запросы», описать конкретную правку, скопировать запрос с текущим кодом и получить новый полный HTML. Вставить его, проверить поведение и сравнить версии в истории. При неудачной правке вернуть прежнюю версию её кнопкой возврата.
5. **Исправление ошибки.** Если игра сообщает об ошибке, открыть строку сообщений. В экспертной диагностике можно скопировать отчёт или подготовить запрос «Исправить с ИИ». Если игра работает не так, как задумано, но ошибок нет, описать ожидаемое и фактическое поведение. Для отдельного упражнения есть примеры в разделе «Исправление ошибок»; им нужна Three.js, которую следует подготовить заранее.
6. **Свой файл.** Сохранить игру с понятным именем, например `my-game.html`. Если есть подготовленные библиотеки, выбрать встраивание внутрь HTML. Открыть именно скачанный файл в браузере и сыграть ещё раз. Отправить его кнопкой «Поделиться» либо из файлового менеджера.

Сначала доведите одну маленькую игру до сохранённого результата. Историю, сравнение, диагностику и библиотеки удобно показывать по мере появления соответствующей задачи. Не требуется разбирать все экспертные функции сразу.

## Запасной сценарий без интернета

1. Открыть заранее скачанный редактор. В экспертном режиме выбрать «Примеры игр» → «Готовые игры» → «Телефон» → «Поймай круг» → «Открыть копию». При замене существующего кода проверить, что нужная версия сохранена.
2. Запустить игру, нажать «Начать игру» и поймать несколько кругов. Остановить предпросмотр.
3. Открыть «Редактирование». Найти `Поймай круг` и заменить на своё название, например `Поймай звезду`. Это меняет надпись, но форма цели останется кругом. Через поиск можно отдельно заменить цвет `#ef687e` на `#25a878`.
4. Запустить снова и проверить название и цвет. Для более свободного задания предложить изменить размер цели; после каждой правки проверять результат. Отмена редакторской правки доступна в «Редактировании»; история хранит версии перед вставкой, импортом и возвратом, а не каждое нажатие клавиши.
5. Сохранить HTML и открыть его отдельно при отключённом интернете. Проверить счёт и управление. ИИ-боты и загрузка новых библиотек в этом сценарии не используются.

## Если участник застрял

| Что произошло | Что сделать |
| --- | --- |
| Кнопка не читает буфер | Удержать палец в поле и выбрать «Вставить». Перед заменой всего кода выделить всё. |
| Ответ ИИ обрезан | Попросить полный HTML, проверить, что скопирован весь блок кода, и вставить заново. |
| Ошибка или пустое поле игры | Посмотреть строку сообщений и диагностику; передать ИИ отчёт и описание действий. Если сообщения нет, описать, что видно на экране. |
| Нужны библиотеки, а сети нет | Перейти к готовой игре без внешних ресурсов или к заранее проверенному автономному HTML. |
| Новая версия стала хуже | Открыть историю, сравнить с прошлой и вернуть нужную запись. |
| Файл не найден или не отправляется | Посмотреть загрузки браузера и папку «Загрузки», затем отправить HTML через файловый менеджер. |
| Сохранены HTML и отдельные JS | Собрать их в одной папке, сохранив имена. Для простого обмена удобнее сохранить библиотеки внутри HTML. |

## Завершение

У каждого участника должен остаться скачанный файл, который он сам открыл и проверил. Автосохранение черновика в браузере не заменяет этот шаг. Для продолжения можно снова открыть редактор и импортировать HTML в экспертном режиме.

Подробности функций, сохранения и ограничений — в [руководстве пользователя](USAGE.md).
