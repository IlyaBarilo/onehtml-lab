Один рисунок, две реализации. Смена основы сохраняет палитру, линии и направление. Размер холста адаптируется к экрану.

Canvas — API браузера без загрузки библиотеки. p5.js даёт короткие команды рисования, цвет, случайные числа и шум: удобно для генеративного дизайна и экспериментов. Сам рисунок не обязан отличаться.
